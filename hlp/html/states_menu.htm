Imaging States Dialog menu commands

The Imaging States dialog has its own menu to manage imaging states files and other options.

File Menu This menu has commands for opening and saving imaging states files.
Save Save current imaging states to current states file.
Save As... Save current imaging states to a different states file.
Load... Read an imaging states file and load them into the dialog.
   
View Menu This menu has commands for controlling what is shown in the table of imaging states
Show Indexes Toggle showing index numbers of states in the table.

Save command (Imaging States dialog - File menu)

Saves the current imaging states to the current imaging states file.

Save As command (Imaging States dialog - File menu)

Saves the current imaging states to a new file, which becomes the current imaging states file.

Load command (Imaging States dialog - File menu)

Use this command to load imaging states from a file and make that file be the 'current imaging states file', which is loaded and saved along with the settings file.  As of SerialEM 4.3 (Nov 2026), imaging states are no longer saved in the settings file but in a separate file, with the name of that file saved in the settings file. This means that you can have multiple sets of imaging states without having to store them in different settings files, and also that you can have multiple settings files all using the same imaging states. You will be asked whether you want to save the current imaging states file first, in case it has changed.

Show Indexes command (Imaging States dialog - View menu)

Use this command to toggle whether index numbers are displayed next to imaging states in the table.
